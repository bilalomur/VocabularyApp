# Vocabulary App

An Android app (Kotlin + Jetpack Compose) for learning vocabulary.

## Features
- Add, edit and delete words with translation and example sentence
- Difficulty levels (Easy / Medium / Hard) and a filter
- Mark words as learned
- Data stored locally with Room

## Tech
Kotlin, Jetpack Compose, Room, Navigation Compose, Coroutines and Flow

## Run
Open the project in Android Studio, sync Gradle, and run on an emulator.
